## Week 1
- Cuneiform was one of the earliest writing systems, developed in Mesopotamia around 5,000 years ago.
- Gutenberg’s movable-type printing press made books cheaper and helped spread knowledge.
- Typewriters standardized text, while monospace fonts became useful for programming because every character has equal width.
## Week 2 
- Binary System: Computers use bits (0 or 1) and bytes (8 bits) to represent data.
- Memory Types: RAM is volatile and loses data when power is off, while SSDs and HDDs store data long-term.
- Data Representation: Computers use binary and hexadecimal to represent numbers, and ASCII to represent text characters.
## Week 3
- Markup Languages: Markdown uses simple symbols for formatting, while HTML uses tags like <p>, <h1>, and <strong>.
- Escaping Characters: Special characters sometimes need escaping, such as &lt; for < and &amp; for & in HTML.
- Unicode: Unicode supports many more characters than ASCII, and UTF-8 is the most widely used encoding on the internet.
## Week 4
- Keyboard Skills: Touch typing and keyboard shortcuts improve typing speed and efficiency.
- Text Editors: VS Code is a popular code editor, while IDEs combine editing with additional development tools.
- Search Techniques: Ctrl + F finds text, wildcards match character sequences, and regular expressions search for specific patterns.
## Week 5
- CLI Advantages: Command-line interfaces allow faster tasks, automation through scripts, and efficient remote access.
- Basic Commands: ls lists files, cd changes directories, pwd shows the current directory, and cp copies files.
- Remote Access: SSH securely connects to remote computers, while SCP securely transfers files between computers.
